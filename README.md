# Marketing Funnel & Conversion Performance Analysis

## 📌 Project Overview
This project analyzes e-commerce clickstream data to understand customer behavior, track marketing funnel events, and evaluate conversion performance using Microsoft Power BI.

## 🎯 Objectives
- Analyze customer interactions across website events.
- Track page views, product views, add-to-cart events, and purchases.
- Understand event distribution using a donut chart.
- Analyze funnel performance and conversion rates.
- Identify opportunities to improve customer engagement and conversions.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Features
- Key Performance Indicator (KPI) cards
- Marketing funnel analysis
- Event type distribution using a donut chart
- Conversion analysis table
- Interactive data visualizations

## 📁 Dataset
E-commerce Clickstream Transactions Dataset

The dataset contains customer sessions, timestamps, event types, product information, transaction amounts, and outcomes.

## 💡 Key Learnings
- Understanding customer browsing behavior
- Analyzing e-commerce funnel events
- Creating measures using DAX
- Building interactive Power BI dashboards
- Presenting data-driven insights
